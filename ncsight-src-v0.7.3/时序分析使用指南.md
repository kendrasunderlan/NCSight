# 时序分析模块 · 使用指南

> 面向「一个变量、很多天的卫星产品」这类数据，一次算出趋势、季节、周期等结论。
> 本文按「先跑通 → 再理解每个指标 → 再避开坑」的顺序写，配实际数据与真实输出。

---

## 〇、三十秒版本

```
文件 → 打开文件夹…            ← 选中装着一堆 nc 的目录
  ↓
右侧「时序分析」面板
  ↓
① 变量：sst      ② 空间统计：区域平均

④ 勾指标：线性趋势 / Mann-Kendall / 季节循环
  ↓

出来是一张诊断图：主面板是序列+趋势线+滑动平均，下面依次是距平/季节循环/功率谱，
底部附统计量表和数据来源说明。进度条在右下角状态栏。

## 一、准备数据：文件怎么放、怎么命名

### 支持三种添加方式

| 方式 | 菜单 | 适用 |
|---|---|---|
| 多选文件 | `文件 → 打开数据集…`（Ctrl+O） | 文件散落各处 |
| **整个文件夹** | `文件 → 打开文件夹…` | **逐日产品最常用** |
| 面板按钮 | 左侧「＋ 打开 nc 文件…」/「文件夹…」 | 同上 |

加载后左侧顶部显示 **数据集（N）** 列表，`●` 标出当前激活的那个。
单击切换、可移除、可清空。**单个文件和一批文件可以混着放**，互不影响。

### 文件名要带日期（很重要）

时间轴的识别顺序是三级兜底：

| 优先级 | 来源 | 说明 |
|---|---|---|
| ① | 文件内的 `time` 变量 | 最可靠，OBPG 的 L3 产品都有 |
| ② | **文件名里的日期** | 逐日产品基本靠这条 |
| ③ | 样本序号 | 前两条都失败时的兜底，图上会明确标注 |

第 ② 条认得这些写法：

| 文件名例子 | 解析结果 |
|---|---|
| `JPSS1_VIIRS.20180105.L3m.DAY.SST.sst.4km.nc` | 2018-01-05 |
| `AQUA_MODIS.2018-01-05.L3m.nc` | 2018-01-05 |
| `sst_2018_01_05.nc` | 2018-01-05 |
| `VIIRS.2018005.L3m.DAY.nc` | 2018-01-05（年积日 005） |
| `chl_201803.nc` | 2018-03-01（只有年月就取当月 1 日） |

> **如果你的文件命名对不上**，有两种处理：在文件里补一个 `time` 变量，
> 或者告诉我你的命名规则，我加一条解析规则。
> **别让它悄悄退化成「样本序号」** —— 那样横轴就不是时间了，
> 趋势的「每年变化」也就没有了物理意义。诊断图的「数据来源」里会写明用了哪条。

### 文件不用事先排序

内部会按识别出的时间**自动排序**。混入不同时次的文件也没关系。

## 二、三个口径，决定结果的物理意义

### 1. 变量

默认自动挑「主轴变量」——会跳过 `qual_sst`、`palette` 这类质量标记与调色板，
直接选 `sst`。如果你要看别的，在下拉框里改。

### 2. 空间统计

| 选项 | 含义 | 什么时候用 |
|---|---|---|
| **区域平均**（默认） | 区域内按 cos(纬度) 加权的平均 | 最常用，看整体变化 |
| 区域中位数 | 抗离群值 | 有异常点、缺测斑块多 |
| 区域最大/最小 | 取极值 | 看极端事件 |
| 区域标准差 | 空间不均匀程度 | 看锋面/涡旋活动强弱 |
| 区域 90/10 分位 | 高分位/低分位 | 看暖/冷事件的强度 |

> **为什么默认按 cos(纬度) 加权**：等距圆柱网格上，高纬度的 1 个格点代表的
> 实际面积比低纬度小得多（1°×1° 在 60°N 只有赤道的 1/2）。不加权算区域平均，
> 等于给高纬度偷偷加了权重，结果会系统性偏冷/偏暖。
> 这一点在南北跨度大的区域（比如整个太平洋）尤其明显。

### 3. 区域范围

沿用「数据」面板的经纬度设置；也可以切换到画布的**「圈选区域」**模式，
在图上直接拉一个框，经纬度会自动填进面板。

> **建议先定区域再看时序**。区域越小时序越"干净"，但样本代表性也越弱；
> 研究北太平洋就看北太平洋，别默认全球。
> 另外：**必须先设区域再做时序**，否则等于把全球平均当指标，很多信号会被抵消掉。

## 三、14 个指标：分别是什么、怎么读

### 分组一：基本统计

| 指标 | 是什么 | 怎么读 |
|---|---|---|
| **统计摘要** | 样本数、均值、标准差、极值、变异系数 | 先看它了解序列的基本量级 |
| **距平序列** | 每个时次减去总体均值 | 正距平 = 偏暖/偏高；用于看年际起伏 |
| **累积距平** | 距平的累积和 | 曲线由升转降（或反之）的位置 = **阶段性转折点**。比逐年距平更容易看出"哪一年开始变了" |
| **滑动平均** | 逐点滑动平均 | 平滑高频扰动，突出低频变化。窗口自动取样本数的 1/10（3~31 点），叠加在主面板上 |

### 分组二：趋势与检验（**最常用**）

| 指标 | 是什么 | 怎么读 |
|---|---|---|
| **线性趋势** | 最小二乘拟合，给出斜率 + 95% 置信区间 + p 值 + R² | 主结论。「0.71 ℃/年 ★★★」表示上升显著。R² 越接近 1，直线拟合得越好（季节性强的序列 R² 会偏低，正常） |
| **Mann-Kendall 检验** | 非参数趋势检验，给出 S、Z、p、Kendall τ | **不要求正态分布**、抗离群值。适合有极端值或明显偏态的序列（如叶绿素、极值统计） |
| **Sen's 斜率** | 所有点对斜率的中位数 | 同样抗离群值，专门给"量值"。**标准做法是 MK 判显著性 + Sen 给变化率** |

**显著性标记**：`★` p<0.05，`★★` p<0.01，`★★★` p<0.001。

> ⚠️ **这三者默认都会先去季节**。这不是可选项，见第五节的"最大的坑"。
> 表里会写明「是否去季节」。

### 分组三：周期与相关

| 指标 | 是什么 | 怎么读 |
|---|---|---|
| **季节循环** | 逐月气候态（多年同月平均），12 个值 | 看峰值月份、季节振幅（最高-最低）。SST 通常 8 月最高 |
| **去季节** | 逐月减去气候态 | 得到季节内/年际信号。诊断图里单独一块 |
| **功率谱** | FFT 功率谱（Hann 窗，已扣均值） | 横轴是**周期（天）**，标注会同时给出天数和近似月/年数。看主周期，例："372 天（≈1.0 年）" |
| **自相关** | 滞后相关函数 | 看记忆性。表里给 1 阶自相关和白噪声 95% 阈值；**去相关时间** = 超过多少滞后才落到阈值内 |

### 分组四：变率与极值

| 指标 | 是什么 | 怎么读 |
|---|---|---|
| **变率与有效自由度** | 去季节标准差 + 有效自由度 | 序列有自相关时**独立样本数少于总样本数**。做显著性检验应该用有效自由度，否则容易"过度显著" |
| **逐月距平** | 先按月平均，再减去各月气候态 | 比逐日距平干净，适合看年际变化 |
| **极值 / 超阈值** | 按分位数（默认 P90）统计超阈次数，逐年出图 | 看极端事件是否变频繁。表里给出上/下阈值、超阈次数与占比 |

## 四、完整实战：从一个月的合成数据里验证出 0.8 ℃/年

下面这组数字全部来自软件的**真实输出**。

### 素材

36 个逐月文件，命名 `TEST_SST_20180115.nc` 到 `TEST_SST_20201215.nc`，每个是
60×120 的网格。这批数据是刻意按已知规律造的：

> **真值**：线性趋势 **+0.80 ℃/年**，季节振幅 **3.0 ℃**（8 月最暖），
> 叠加 σ=0.35 ℃ 的随机噪声。

目的就是看软件能不能把这些真值算回来。

### 操作

1. `文件 → 打开文件夹…` 选中这 36 个文件所在目录
   → 左侧显示「数据集（36）」，状态栏提示"已加入 36 个文件 —— 到时序分析面板勾选指标"
2. 右侧「时序分析」面板：
   - 变量 `sst`
   - 空间统计「区域平均」
   - 区域默认全球（这批是合成数据，全球即可）
   - 勾选：线性趋势、Mann-Kendall、Sen's 斜率、季节循环、功率谱、统计摘要
3. 点「计算并绘制诊断图」

进度条会依次显示「读取 12/36：TEST_SST_20191215.nc」→「计算指标 4/5：功率谱」。

### 结果

```

  季节信号强度  0.98

  趋势判定      显著上升 ★★★
  统计量 S      438.0
  标准化 Z      5.952

【Sen's 斜率】

【季节循环】

### 怎么解读

| 项 | 真值 | 算得 | 结论 |
|---|---|---|---|
| 线性趋势 | 0.80 ℃/年 | **0.711** | ✅ 差异来自噪声，95% CI ±0.087 之内 |
| 显著性 | 应显著 | p = 7.7e-18 | ✅ 极显著 |
| MK 判定 | 上升 | 显著上升 ★★★ | ✅ |
| Sen 斜率 | 0.80 | 0.664 | ✅ |
| 季节峰值月 | 8 月 | **8 月** | ✅ 完全一致 |
| 季节振幅 | 6.00 ℃ | 6.40 | ✅ |
| 谱主周期 | 12 个月 | **372 天 ≈ 12.2 个月** | ✅ |

**四条独立路径（最小二乘 / MK / Sen / FFT）互相印证**，结论才站得住。
如果只有一条路径说"有趋势"，先别急着写进论文。

## 五、坑：最大的一个是季节信号会"偷走"趋势

### 症状

上面那批数据，如果**不先去季节**直接拟合，得到的是：

```
变化率  1.2533 degree_C/年   ← 真值 0.80，高了 57%
```

### 原因

序列 = 趋势项 + 季节项 + 噪声。季节项 `3·cos(2π(m-8)/12)` 的**相位与时间项并不严格正交**，
最小二乘会把一部分季节信号算成趋势。

### 软件的应对

**线性趋势 / Mann-Kendall / Sen's 斜率默认先去季节**，并自动判断季节强度：
按月分组的组间方差占比 ≥ 0.15 且样本 ≥ 8 才去。表里会写明「是否去季节」。

去季节后回到 **0.711 ℃/年**（真值 0.80）。

> 这条有回归测试守着（`tests/test_series.py::test_不去季节会让趋势偏大`），
> 以后不会被改坏。

### 你自己要注意的

- 看 `R²` 时别忘了季节性强的序列 R² 天然偏低 —— **R² 低不代表趋势不存在**
- 如果研究的就是季节内信号（比如季节内振荡），用「去季节」指标的输出，别用原始序列
- 序列短于 2 年时，趋势和季节很难分开，结论要谨慎

## 六、其它常见问题

**Q：为什么趋势的「每十年」和「变化率×10」对不上？**
对得上，只是单位不同：`0.7109 ℃/年` → `7.1091 ℃/10年`。

**Q：p 值很小，但我觉得不可信。**
看一眼「有效自由度」。序列自相关强时（1 阶自相关 > 0.5），
独立样本数远少于总样本数，标准检验会**高估显著性**。这是气候序列的通病。

**Q：样本数太少怎么办？**
MK 要求 ≥ 4 个点，功率谱要求 ≥ 8 个点，少于这个数软件会直接说明而不是硬算。
月尺度看年际变化，建议至少 3 年（36 个点）。

**Q：能不能同时看多个变量？**
一次一个变量。要看 SST 和 Chl-a 的关系，分别跑两次，导出 CSV 后用「导出」里的
数值做相关分析（多变量相关在计划中）。

**Q：算几百个文件要多久？**
读取已经按区域窗口优化过，只看一个区域时约 **0.1 秒/文件**：
365 个文件约 35 秒。若不设区域看全球，会慢几十倍——**所以先定区域很重要**。

**Q：中途想换区域重新算，要重开文件吗？**
不用。改「数据」面板里的经纬度，再点一次「计算并绘制」即可。

**Q：怎么把结论导出？**
诊断图用 `文件 → 导出图像…`（支持 PDF/SVG，投稿用）；
数值表可以用命令行版 `--indicators all` 打印，或从「导出 → 数据」拿 CSV。

## 七、指标速查表

| 你想回答的问题 | 用哪个指标 |
|---|---|
| 这个区域在变暖还是变冷？变多快？ | 线性趋势（+ MK + Sen 互相印证） |
| 变化显著吗？ | MK 的 p 值 / 线性趋势的 p 值 |
| 数据有离群值，趋势还可靠吗？ | MK + Sen（都是抗离群值的非参数方法） |
| 一年里什么时候最暖？振幅多大？ | 季节循环 |
| 去掉季节后，还剩什么信号？ | 去季节 |
| 有没有年际振荡？周期多长？ | 功率谱 |
| 序列记忆性多强？ | 自相关、变率与有效自由度 |
| 哪一年开始发生转折？ | 累积距平 |
| 极端事件变频繁了吗？ | 极值 / 超阈值 |
| 整体量级和离散程度？ | 统计摘要 |
