# NCSight 使用说明

> 面向「日常要把 nc 数据画成图」的海洋遥感工作流。全文按你熟悉的 Panoply 操作习惯来对照说明。

---

## 一、最短路径：双击就能用

打包完成后，目录结构是这样的（和 Panoply 的 `exe + jars` 是同一个思路）：

```
NCSight/
├── NCSight.exe          ← 双击这个，启动图形界面
├── ncsight-cli.exe      ← 命令行版，批量出图用
└── _internal/           ← 所有依赖、离线底图、出图预设
```

**三步开始：**

1. 把整个 `NCSight` 文件夹**拷到任意位置**（比如桌面）。
2. 双击 `NCSight.exe`。
3. 菜单 `文件 → 打开数据集…`，选你的 nc 文件。

**两个注意点：**

- `_internal` 文件夹**必须和 exe 放在一起**，不能只把 exe 单独拷走。
  （这点和 Panoply 要求 jars 文件夹不能移动是一样的道理。）
- 首次启动会慢一点（几秒），之后就快了。因为要加载 Qt 和 matplotlib。

**想放桌面更方便：** 右键 `NCSight.exe` → `发送到` → `桌面快捷方式`。

## 二、界面一眼看懂

打开数据后是三栏布局：

```
┌────────────┬──────────────────────────┬─────────────┐
│  变量树     │       绘图画布            │  绘图控制    │
│            │                          │             │
│ 全球/区域场  │   （地图就画在这里）       │ 变量与图型   │
│  ├ sst     │                          │ 维度切片     │
│  └ qual_sst│                          │ 区域范围     │
│            │                          │ 数值范围     │
│ ─ 属性 ─    │                          │ 色表         │
│ 维度/单位/   │                          │ 经纬网       │
│ 打包参数     │                          │ 底图叠加     │
│            │                          │ 等值线       │
│            │                          │ 筛选与分析   │
│            │                          │ 版式         │
└────────────┴──────────────────────────┴─────────────┘
   状态栏：鼠标处的经纬度与数值  |  统计量  |  版本号
```

**和 Panoply 的对照：**

| 你在 Panoply 里做的事 | 在 NCSight 里 |
|---|---|
| `File → Open…` | `文件 → 打开数据集…`（或 Ctrl+O） |
| Sources 窗口里选变量 | 左栏变量树，**双击变量直接出图** |
| `Plot → Create Plot…` | 选中变量就自动出图，不用点 |
| Window → 各个 Controls 面板 | 右栏直接堆叠展示，不用来回切窗口 |
| Scale / Map / Overlays / Labels 面板 | 右栏对应的「数值范围 / 色标 / 地图 / 版式」折叠块 |
| 那一长串 Plot Size 档位 | 版式里的「图幅尺寸」预设：单栏 8.3cm / 双栏 17.1cm / 幻灯片 |
| 没有的功能 | **筛选与分析**：抹掉陆地、质量过滤、距平、矢量场 |

## 三、画布上的四种鼠标模式

工具栏中间有四个模式按钮，也可以在画布上直接操作：

| 模式 | 干什么 | 怎么用 |
|---|---|---|
| **取值** | 看某个点是多少 | 鼠标在图上移动，**状态栏**实时显示「经度 / 纬度 / 数值」 |
| **框选缩放** | 放大到某片区域 | 按住左键拉一个框，松手就放大 |
| **平移** | 拖动画面 | 按住左键拖动 |
| **圈选区域** | 划定研究区 | 拉一个框，松手后经纬度**自动填进右栏「区域范围」**并重新出图 |

工具栏最右边的「重置」按钮（或 Ctrl+0）回到原始范围。

## 四、最常用的五件事

### 1. 换投影

右栏「地图 → 投影」下拉框。等距圆柱最快；换成 Robinson / 正射 / 墨卡托等会自动
**先降采样再投影** —— 这是必须的，否则 4320×8640 的全球场会卡住好几分钟。

正射、兰勃特、方位等投影需要「中心经度 / 中心纬度」，就在投影下面那两格。

### 2. 换成区域图

两种办法：
- 用「圈选区域」模式在图上拉框（推荐，最快）
- 右栏「区域范围」手动输入经纬度，勾上「启用区域裁切」

### 3. 调色标

右栏「数值范围」：
- **默认是自动的**，会优先用数据自带的建议范围（OBPG 产品里带 `display_min/max`），
  没有就取 1%~99% 分位数
- 想手动：直接改最小/最大值，会自动切到手动模式
- **做距平图**：点「居中于零」，色表选 `balance` 或 `vik`

「色表」里 70 多个配色，按来源分组：海洋学专用（cmocean）、科学感知均匀（cmcrameri）、
matplotlib、ColorBrewer。默认 `auto` 会用文件内嵌的 OBPG 调色板。

### 4. 只留海洋（抹掉陆地）

右栏最下面的「筛选与分析 → 掩膜」：
- 勾「抹掉陆地（只保留海洋）」
- 或者「按数值区间保留」填 [15, 30]，只留这个温度区间
- 有质量标记变量（如 `qual_sst`）时，用「质量变量 + 接受等级」过滤低质量像元

> 提示：掩膜运算量随格点数增长。**先设「区域范围」再打掩膜**会快很多。

### 5. 导出图

`文件 → 保存图像…`（Ctrl+S），选格式：

| 格式 | 什么时候用 |
|---|---|
| **PDF / SVG** | **投稿插图** —— 矢量、无损缩放、文字可编辑 |
| PNG | 预览、插 PPT |
| TIFF | 印刷 |
| — | 也可以 `文件 → 复制图像到剪贴板` 直接粘进 Word/PPT |

导出的 DPI 默认 300，可以在对话框里改。

## 五、让出图可复现（这是最省事的习惯）

`文件 → 保存绘图配置…` 把当前这套参数存成一个 `.plot.yaml`。
以后同样的图，一条命令就能重画：

```bash
ncsight-cli.exe plot  D:\data\sst.nc  --spec  sst.plot.yaml  -o  sst.png
```

这个 YAML 是纯文本，**可以放进 git**，跟论文/代码一起被追溯。

软件里还内置了 6 套出图预设，在 `_internal/ncsight/presets/` 下，可以直接用：

```bash
ncsight-cli.exe plot data.nc --spec "区域_西北太平洋.yaml" -o 西北太平洋.png
```

## 六、批量出图（命令行，做一次省一天）

`ncsight-cli.exe` 是个独立的小黑窗口程序：

```bash
# 把整个目录的数据全部出图（一整天 / 一年的产品）
ncsight-cli.exe batch  D:\ncdata  -o  D:\figures  --format pdf

# 沿时间维逐帧出图
ncsight-cli.exe batch  data.nc  -o  D:\figures  --over-dim time

# 看看数据集里有什么
ncsight-cli.exe info  data.nc

# 出图并顺手存下配置
ncsight-cli.exe plot  data.nc  -v sst  --projection Robinson  -o sst.png  --save-spec sst.plot.yaml

# 导出数据
ncsight-cli.exe export  data.nc  -v sst  --format npz  -o sst.npz

# 看所有可用参数
ncsight-cli.exe options
```

批量跑完会在输出目录生成一个 `_batch_report.txt`，记录每张图的状态和耗时。

## 七、批量分析：一次加载多个 nc 文件

这是本软件相比 Panoply 提升最大的一块。逐日卫星产品动辄几百个文件，
传统做法要写脚本循环读文件、算区域平均、拼时间轴、再逐个算趋势 ——
现在选好文件点一下就行。

### 1. 把文件加进来（三种方式，效果一样）

| 方式 | 操作 |
|---|---|
| 文件 | `文件 → 打开数据集…`（**可按住 Ctrl / Shift 多选**） |
| 文件夹 | `文件 → 打开文件夹…` —— 把一个目录下所有 `.nc` / `.nc4` 一次加进来 |
| 左侧面板 | 顶部「＋ 打开 nc 文件…」/「文件夹…」按钮 |

加载后左侧面板顶部会显示 **数据集（N）** 列表：

```
数据集（36）
   ● TEST_SST_20180115.nc      ← ● 表示当前激活的那个
     TEST_SST_20180215.nc
     TEST_SST_20180315.nc
     ...
```

- **单击**列表里的文件 = 切换当前数据集（变量树和画布跟着变）
- 「移除选中」/「清空」可以把文件移出去
- 单个文件和一批文件可以混着放，互不影响

### 2. 算指标

到右侧 **「时序分析」** 面板：

1. 选 **变量**（默认自动挑主轴变量，会跳过 `qual_*` 质量标记）
2. 选 **空间统计**（区域平均 / 最大 / 最小 / 中位数 / 标准差 / P90 / P10）
3. 选 **区域范围**：沿用「数据」面板里的设置，也可以先切换到
   「圈选区域」模式在图上拉个框
4. 勾选要算的 **科学指标**
5. 点 **「计算并绘制诊断图」**

### 3. 得到的诊断图

一张图里包含：原始序列 + 趋势线 + 滑动平均（主面板），
以及距平 / 季节循环 / 功率谱等各自成块，底部附统计量表和数据来源说明。

> **关于时间轴**：优先读文件里的 `time` 变量；读不到就从**文件名的日期**解析
> （认 `20180105`、`2018-01-05`、`2018_01_05`、`.2018005.` 年积日、`201803` 年月）；
> 都没有才退回样本序号，并在图的「数据来源」里明确标注。
>
> **关于趋势**：线性趋势 / MK 检验 / Sen 斜率都会**先去掉季节循环再算**。
> 这一步不能省 —— 季节振幅通常远大于年际趋势，直接拟合会被季节信号
> 带偏几十个百分点（实测偏差可达 57%）。图上的「是否去季节」会写明。

### 4. 命令行同样可以批量

```bash
ncsight-cli.exe timeseries "E:\data\*.nc" -o trend.png `
    --indicators trend,mk,sen,seasonal,spectrum `
    --bbox 110 140 5 35 --stat mean
```

`--indicators all` 算全部 14 个指标；`--point 130 20` 取单点。

### 5. 想回到单张地图

取消「时序分析」面板里的 **「用时序模式出图」** 勾选，
或者直接点左侧变量树里的任意变量，就回到普通地图模式。

## 八、常见问题



**Q：双击没反应 / 弹「启动失败」？**
A：错误堆栈会写到 `C:\Users\<你>\.ncsight\crash.log`。最常见的原因是
`_internal` 文件夹被移动或删除了 —— 它必须和 exe 在一起。

**Q：海岸线画不出来？**
A：离线底图已打包在 `_internal/cartopy_data/` 里。如果这个目录丢了，
程序会尝试联网下载。可以跑一下自检确认：

```bash
NCSight.exe --selftest 你的数据.nc
```

**Q：图很卡 / 内存不够？**
A：先在「区域范围」里裁小一点再操作。全球 4km 网格有 3700 万个格点，
全量渲染本身很重。另外右栏「地图」里如果不是必须，用等距圆柱投影最快。

**Q：中文变成方框？**
A：正式打包版不会出现。如果你是直接用 Python 跑源码，说明系统缺少中文字体
（`Microsoft YaHei` 之类）。装一下字体即可。

**Q：想改底图 / 加自己的边界？**
A：右栏「底图叠加 → 自定义 .shp」可以叠加你的研究区、断面、专属经济区。

**Q：我拿到的是源码，还没打包？**
A：跑一条命令打包成 exe：

```bash
python scripts\build_exe.py
```

## 十、自己重新打包（改了代码之后）

源码改了想重新出 exe，两条命令：

```bash
# 首次：建一个打包专用的干净环境（只需做一次，约 10 分钟）
python scripts\make_build_env.py

# 打包 + 自动自检
python scripts\build_exe.py --clean
```

产物在 `dist\NCSight\`。脚本最后会自动跑一次 exe 自检，把
「Qt 插件 → 离线底图 → 打开数据 → 投影渲染 → 存图 → 导出数据」
整条链路验一遍。也可以随时手动自检：

```bash
dist\NCSight\NCSight.exe --selftest  你的数据.nc
```

### 关于体积

当前产物约 **390 MB**（`NCSight.exe` 9 MB + `_internal` 368 MB）。构成大致是：

| 部分 | 约 |
|---|---|
| Qt（PySide6） | 90 MB |
| scipy | 75 MB |
| Python 运行时 + OpenBLAS | 60 MB |
| cartopy 离线底图（110m/50m/10m） | 34 MB |
| matplotlib + numpy + netCDF4 + 其他 | 120 MB |

**为什么需要单独的打包环境**：直接拿日常那套 conda 环境打包，会踩两个坑——
一是它装了整套机器学习栈（torch / opencv / spacy / transformers…），
PyInstaller 会顺着依赖图全扫进来；二是 conda 版 numpy 链到 Intel MKL，
PyInstaller 会把所有 CPU 内核变体（`mkl_core` / `mkl_avx512` / `mkl_pgi_thread` …）
都塞进去，光这一项就 **600 MB**。

打包专用环境用 pip 版 numpy/scipy（OpenBLAS，无 MKL），
所以产物从约 **970 MB 降到约 390 MB**。

### 分发注意

- 必须**整个文件夹**一起拷贝，`_internal` 不能丢、不能单独移动 exe
- 如果对方机器装了杀毒软件，首次运行可能被拦截，加个信任即可
  （PyInstaller 打出来的程序被误报是常见现象）
- 这个 exe **只能在 Windows 上跑**，且是 64 位
